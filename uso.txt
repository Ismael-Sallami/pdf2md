# ── OCR e idiomas ───────────────────────────────────────────────
# Tesseract debe estar instalado en el sistema. El OCR solo se aplica a
# páginas sin texto extraíble (PDFs escaneados / imágenes).
# Con --ocr se renderiza a un mínimo de 300 DPI automáticamente.

# Instalar idiomas (Debian/Ubuntu):
#   sudo apt install tesseract-ocr          # base (inglés incluido)
#   sudo apt install tesseract-ocr-spa      # español
# Ver idiomas instalados:  tesseract --list-langs

# --lang elige el modelo de reconocimiento (NO traduce, mejora precisión).
# El default es spa+eng (prueba español e inglés). Los idiomas no instalados
# se ignoran con un aviso y se sigue con los disponibles.

# Español (default, no hace falta --lang):
python pdf_to_md.py documento_es.pdf --ocr

# Inglés:
python pdf_to_md.py documento_en.pdf --ocr --lang eng

# Forzar solo español:
python pdf_to_md.py documento.pdf --ocr --lang spa

# Documento mixto + más resolución:
python pdf_to_md.py documento.pdf --ocr --lang spa+eng --dpi 300
